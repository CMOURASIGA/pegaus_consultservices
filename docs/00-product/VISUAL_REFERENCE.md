# Visual Reference - Pegasus

## Objetivo

Registrar uma referência conceitual inicial para futura identidade visual do projeto Pegasus.

## Referência selecionada

A referência desejada é um Pegasus em line art minimalista, fundo branco, traço preto, aparência limpa e tecnológica.

Referência externa utilizada durante a definição:

- Pinterest / UNOM design: https://www.pinterest.com/pin/line-art-pegasus-logo-in-2025--739927413816130023/
- Imagem de referência: https://i.pinimg.com/736x/9c/04/44/9c04445debea841337a7935c8baee7fe.jpg

## Diretriz

Esta imagem é somente referência visual e não deve ser tratada como ativo oficial/licenciado do projeto.

Antes de qualquer uso como logo, ícone, material comercial ou identidade oficial, deverá ser criada uma arte original própria, inspirada apenas no conceito geral de line art minimalista do Pegasus e respeitando direitos autorais/licenciamento.

## Características que devem ser preservadas na futura arte própria

- Pegasus inteiro ou silhueta claramente reconhecível;
- linhas minimalistas;
- fundo branco;
- alta legibilidade em tamanhos pequenos;
- possibilidade de versão monocromática;
- possibilidade de versão em azul no futuro;
- visual compatível com interface tecnológica e assistente pessoal;
- evitar estética excessivamente mitológica, medieval ou ornamental.
